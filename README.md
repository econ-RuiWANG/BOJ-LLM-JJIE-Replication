# Bank of Japan inflation diagnosis — replication package

Rui Wang, *How Has the Bank of Japan Explained the Causes of Price Changes? Analyzing the Minutes of Monetary Policy Meetings with a Large Language Model.*

[Download the versioned JJIE replication package](https://github.com/econ-RuiWANG/BOJ-LLM-JJIE-Replication/releases/tag/2026-11-26).

The archive contains the data that can be shared, saved text-free classification labels, estimated results, replication code, and source-specific access instructions. It can reproduce the baseline indices and four of the manuscript's baseline macroeconomic regressions using the included data. The archive documents the access conditions for the remaining inputs.
